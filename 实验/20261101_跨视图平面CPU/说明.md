# 跨视图共同平面：稀疏 CPU 门槛

运行：`C:\Users\guofa\miniconda3\envs\gaussian_splatting\python.exe crossview_plane.py --output results.json`。

输入为原始 `confirm_v1/scan37,40/view_000.npz` 的深度、权重、`host_target` 与 `normal_target`，以及 `observations_v1` 的 COLMAP 和三张原图。源索引 SHA、trace metadata SHA、相机姿态和焦距均在运行时核对。记录深度是 view0 相机 z，法向为 view0 相机坐标系。半分辨率记录像素 `(x,y)` 映到原图整数中心 `(2x+0.5,2y+0.5)`。原始主机 CUDA 二进制的构建源码仍有溯源缺口。

固定种子 20261101、每场 32 条不按效果筛选的射线；view0/1 求解、view2 评价。每条在 129 个均匀极线位置形成初值，最多取四个不同局部极小，每支最多八步阻尼 Newton。仅在孤立收敛且 Hessian 正定时接受；其余回退原生深度和法向。修正版纯光度与联合方法各用相同预算；相对旧版，回溯试探次数从 5 增至 17，故不能声称新旧版计算预算全不变。129 个初值、最多四分支和最多八 Newton 步不变。原始训练 CUDA NCC 用相关系数平方和 `5e-6` 方差门槛；本原型三组共同使用灰度有符号 `1-ZNCC`、`1e-8` 方差门槛。两个 loss 数值不能互换。

`results.json` 是旧版固定步长数值导数的失败记录，其 Hessian 跨越双线性图像像素边界，不能据此判断目标定义。`results_autograd.json` 是修正版同样 64 条射线的原始结果。`results_autograd_stats_corrected.json` 只重算固定集合统计，没有重跑求解器；其中记有原始结果 SHA。修正版在当前双线性单元内通过 PyTorch float64 一、二阶自动微分求 Newton 步，导数点距单元边界小于 `1e-6` 像素时拒绝；每步限制平面参数变化与 0.25 像素最大贴片运动。独立同单元中心差分核对梯度与 Hessian，不能称为跨边界全局 Hessian。

逐射线结果保留分支数、求解失败原因、无效回退、view2 光度成本与耗时。原生 view2 有效的射线索引预先构成固定共同可评集合（scan37 为 29/32，scan40 为 24/32）；三方法在同一索引集合计算均值和中位数，任何候选在该集合缺失成本都报错。**所报均值和中位数是固定可评子集 29/24 条的统计，不是全 32 条均值；32 是覆盖、无效与回退计数的分母。**有限差分验证从记录 `depth/weight` 到 `-log S` 的显式梯度；对全部六个孤立收敛正定联合分支，逐一检查某成员极线坐标扰动的局部隐式解导数，六个均通过。尚未对完整高斯参数反传。view2 是局部求解留出视图，但这些原图曾参与冻结模型训练，不是新模型重建精度或盲评。

预定门槛：两场各至少八个可靠改进分支，含回退全 32 条 view2 均值和中位同时优于原生与同预算纯光度，数值梯度通过。门槛失败，停止此固定版本，不扫参救结果。
