# 跨视图共同平面：稀疏 CPU 门槛

运行：`C:\Users\guofa\miniconda3\envs\gaussian_splatting\python.exe crossview_plane.py --output results.json`。

输入为原始 `confirm_v1/scan37,40/view_000.npz` 的深度、权重、`host_target` 与 `normal_target`，以及 `observations_v1` 的 COLMAP 和三张原图。源索引 SHA、trace metadata SHA、相机姿态和焦距均在运行时核对。记录深度是 view0 相机 z，法向为 view0 相机坐标系。半分辨率记录像素 `(x,y)` 映到原图整数中心 `(2x+0.5,2y+0.5)`。原始主机 CUDA 二进制的构建源码仍有溯源缺口。

固定种子 20261101、每场 32 条不按效果筛选的射线；view0/1 求解、view2 评价。每条在 129 个均匀极线位置形成初值，最多取四个不同局部极小，每支最多八步阻尼 Newton。仅在孤立收敛且 Hessian 正定时接受；其余回退原生深度和法向。纯光度与联合方法预算一致。原始训练 CUDA NCC 用相关系数平方和 `5e-6` 方差门槛；本原型三组共同使用灰度有符号 `1-ZNCC`、`1e-8` 方差门槛。两个 loss 数值不能互换。

`results.json` 保留每条射线、分支数、无效回退、view2 光度成本与耗时。成本为 null 的射线仍算在 32 条分母里，因此不把有效子集平均冒充完整平均。有限差分仅验证从记录 `depth/weight` 到 `-log S` 的显式梯度，尚未对高斯参数反传。只有孤立收敛正定分支才允许验证隐式解梯度；本次没有此类分支，因此未进行。view2 是局部求解留出视图，但这些原图曾参与冻结模型训练，不是新模型重建精度或盲评。

预定门槛：两场各至少八个可靠改进分支，含回退全 32 条 view2 均值和中位同时优于原生与同预算纯光度，数值梯度通过。门槛失败，停止此固定版本，不扫参救结果。
