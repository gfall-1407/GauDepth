# scan110 两中心局部一步原型归档

本版停止于更新前的 CPU 几何门禁；没有接入真实宿主损失、执行 Adam 一步、训练或使用 GPU。固定输入为 G5 capture `native_members.npz`（SHA-256 `74fbd05c3a2c10549adca00f885cdb39c525d003ce120d1a3d593c7feb78d6ef`）和 root 表（SHA-256 `0b3a600725142558e69fde7aa45d3f2eaa0b715d487d59d784207a086e4a73bf`）。固定中心为 ray17/root2、ray24/root6；旧 `results.json` SHA-256 `09c3d166d22069a33de0cef7071c78c54f2b9f12d0ba9d1988a5a67065265919`，保留原文件不改。

ray17 在第一个邻像素的第 1 子步 `xy=[386.75,259.75]`，原 bracket `[2.878044205,2.884722065]` 内可求得残差约 `1.29e-13` 的根 `z=2.880247398`，但曲率为 **+479642.34**，违反已冻结的稳定根条件。这是本版两中心局部 normal 无法成立的决定性失败。ray24 在第一个邻像素第 3 子步 `xy=[649.25,332.25]` 的原 bracket `[3.232416437,3.259634287]` 两端 F 同为正；后续独立复核指出合法稳定根约在原右端外 `0.000611927`，属于**静态 bracket 不再包根**，不能说根消失。详细 F、eigengap、Fz、曲率见独立的 `branch_fields.json`，SHA-256 `6e7bb25be51204a5727896287836d4d10865a455837c599d52a53345b74e80b4`。

当前四子步代码在每个坐标各用同一冻结 bracket 独立二分；它没有使用上一步根作 predictor/corrector，因此不是严格的连续分支追踪，不能以它证明所有可能的追踪方式都失败。研究裁决是不为本版移动边界、放宽稳定条件、调步长或改选根来救这两中心训练。数学根与参数梯度模块作为独立资产保留；此失败不否定以后另行设计的主动塑形训练。

`one_step_contract.py` 新增的共享 seed0 新初始化并冻结 PGSR appearance、完整 PLY 哈希门禁和 fresh Adam 作用域仅通过 CPU 辅助测试，**没有接到真实 host update**；它不是原训练第 7001 步的优化器/appearance 恢复。正确同源原 7k PLY 应为 `36,010,340` bytes、SHA-256 `733bd5ad69246915e7777b740b1891a253624b1d2232df5f19e79a557de78aa7`；现本地 `64,096,748` bytes、SHA `057aa57fae1d52c4de2e3611075d3b4ef80929fd6edad3e1d2a32a040c5a2a1e` 的 PLY 不是该模型。G5 无卡取回正确文件的操作此前被自动审批拒绝，父线程另向用户请求明确授权，当前未取回。**取数受阻与上述 CPU 门禁失败彼此独立**；即使取得正确 PLY，也不自动恢复本版训练。
