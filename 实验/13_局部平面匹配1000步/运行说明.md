# 固定局部平面正则：匹配 1000 更新两臂

本入口以已审 `6ce1b1b739247f5dbfb3eb68fc0a318fa0ba580d` 的 32 窗口、2420 次正质量出现、1836 个共享高斯 ID 为唯一附加目标。`matched_plane_regularizer.py` 用当前全模型原始中心和四元数、固定轴/归属/潜在平面、初始贡献质量求数据残差 `R`；不重拟合、不断开中心/旋转梯度，scale/opacity 不从这项直接获梯度。A 只用原宿主损失，B 另加 `lambda*R`，其余完整宿主参数组两臂均更新。它是局部固定目标的受控续训，**不是标准 30k、动态分层或原 Adam 精确恢复**。

输入必须是 scan110 原 7k PLY，142892 行、36010340 字节、SHA256 `733bd5ad69246915e7777b740b1891a253624b1d2232df5f19e79a557de78aa7`；本地尚缺此正确文件。capture 与 frozen results 也必须符合代码固定 SHA；COLMAP 两文件需和结果记录一致。源码宿主 `train.py`、`scene`、`gaussian_renderer`、loss、CUDA 等从 main `8474727` 到基准 `6ce1b1b` 无差异。G5 编译扩展另外核实际来源，不能按 Git HEAD 推断缓存相同。

运行前 G5 需由总控核实例身份/余额、取数权限、独立关机和实际构建 manifest；本提交尚未获推送或 GPU 执行审查。编译 manifest 记录 wrapper 实际绑定的原生后端、模块路径与 SHA，以及 Python/Torch/CUDA 版本。自有 rasterizer/warp 必须核源码 Git HEAD、全部相关源码（含 sample、C++ 包装、头文件、GLM）及实际构建记录。历史预装 fused_ssim/simple-knn 若构建来源无法追溯，可明确记 `unverified`；仍须核实际绑定、二进制和环境，不能伪造来源或强制重装。当前本地无 fused_ssim，且部分子模块源码为空，部署仍待 G5 核验。以下仅是结构示例，不能将占位符用于运行：

第二条只隔离准备 A-E/A-M/B-E/B-M 四份同模型快照，不执行重建。它打印每项正式 `mesh_extract.py` 与 `evaluate_dtu_mesh.py` 命令，四项分别执行并保存 overall、d2s、s2d；`depth_ratio=0` 仅 Expected，`depth_ratio=1` 仅原生 Median。A/B 的 0049 初态 RGB 与 1000 更新后全训练相机 RGB 指标另存 `rgb_train.json`。后续须采用同 DTU、mask、TSDF 与分辨率，预注册正向判据是 B 的 **两种** readout overall 均优于 A，不可用 R 下降代替。

独立 output-root 必须不存在；两臂按 A→B，同初态 SHA、新 Adam state SHA、零初始化但正常训练的 PGSR appearance、同相机及邻相机列表、固定 seed0 抽样序列。虚拟 7001→8000 原 30k LR，恰 1000 次 `optimizer.step()`，0/500/1000 后保存模型和 optimizer。filter 从 PLY 加载后固定；无 densify/prune/opacity reset。共同初态先算 `lambda=.01*L_RGB,0049/R0`，记录并固定，不试别的权重。任何正质量几何极点/非有限即失败并保存最近已完成边界或单独标记的 partial，不能删成员修复。

当前本地只完成 CPU captured-subset/mock 门禁；Windows 环境的 Python 版本无法导入宿主部分 Python 3.9+ 类型注解，且缺 Linux CUDA 扩展，因此宿主整帧和真实 Adam 更新**未运行**。预留总批 90 分钟上限+10 分钟保存宽限，仍须独立平台停机；当前不据 CPU 运行时间承诺 GPU 速度或显存。系统盘需预留两臂初态/500/1000 模型与 optimizer、四份 mesh 输入及重建输出空间，实际空间和 GPU 内存须在获准实例上预检。没有完整同源 PLY 和扩展构建来源证据时不得执行。
