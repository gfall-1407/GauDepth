## 采样

从仓库根目录运行。需要现有RaDe-GS依赖、PyTorch/CUDA编译环境。新扩展名`gaudepth_layers03_reader_v1`，独立构建目录为本目录`构建/`，使用`-O3 --use_fast_math`，不设置固定GPU架构。第一次编译及云端CUDA验证必须由总控执行。

```bash
python 实验/03_高斯场层归属探索/sample.py \
  -m /root/autodl-tmp/GauDepth/outtest/scan24 \
  -s /root/autodl-tmp/DTU_MVS_Data/scan24 \
  --iteration 30000 --views 0 --samples 256 --seed 20261022 \
  --host-build-provenance '填写已核验的原安装扩展源码/构建来源及比对结论' \
  --output 实验/03_高斯场层归属探索/结果/20261022_夜间/scan24
```

`-s`必须使用现场核对的数据路径；上面的DTU路径是示例，不能凭示例直接假定存在。`-m`也接受明确的`point_cloud/iteration_30000`目录，但迭代号必须一致。`cfg_args`只解析Namespace字面量，不执行配置中的Python代码。默认读取train相机列表，`--views 0,1,2`是该列表索引，`--split test`切换列表。

优先用`camera.gt_mask > .5`。外部GT mask可显式指定`--mask-dir 路径 --mask-template '{image_name}.png'`；也支持`{view}`，缺失即报错，最近邻调整到渲染尺寸并记录原文件SHA256。未提供GT时，从宿主opacity>.5的像素均匀无放回采样，**只能称渲染覆盖范围，不能称真实前景**。候选不足256条时记录实际数量。`--opacity-threshold`可显式调整并进入元数据，不自动选参。额外定性异常像素使用重复`--extra-pixel 0:640:480`；与随机样本分开存储，即使重复像素也不会混入统计。

Scene在load_iteration时的`multi_view.json`写入临时重定向到新输出目录，退出后恢复Python作用域；任何其他Scene写入会报错。数据加载器如试图新建源PLY也报错，保护原始数据。禁止输出到原模型目录或其子目录；非空输出目录拒绝覆盖。PLY运行前后核对SHA256，不写原模型。每个view结束后独立落盘，前一view无需等待整批完成。

读取实际`GeometryState::fromChunk`顺序：depths(float)、ray_planes(float4)、normals(float4)、clamped(bool*3)、internal_radii(int)、means2D(float2)、conic_opacity(float4)，每段128字节对齐；ImageState先n_contrib(uint32*2WH)再ranges(uint2*WH)，BinningState首段为排序point_list。tile为16x16。不能根据struct声明猜布局；现场须核对**安装二进制**来源，源码同提交不保证已安装扩展一致。记录包/二进制绝对路径、SHA256和操作者填写的构建来源，而不伪称SHA可自动证明来源。

保持宿主原接受顺序、alpha上限.99、alpha下限1/255及`next_T<1e-4`时不接受当前项并结束；保存所有已接受成员，不因w小而剔除。代表深度为`(plane.x*dx+plane.y*dy+plane.z)/||ray||`，即camera-z，而非高斯中心深度或沿射线距离。fx/fy使用float tan_fov语义，与宿主一致。

每条采样射线均从同一buffer replay expected、median、opacity，并执行`torch.testing.assert_close(rtol=2e-5, atol=2e-6)`；失败不会写该view为已通过。容量不足先统计完整count，再增容重取，不静默截断。另从完整记录按原接受顺序以CPU float32累加`sum(w*normal)`，按宿主`NORMALIZE_EPS=1e-12`归一化，和原forward normal的采样像素执行`assert_close(rtol=2e-4, atol=2e-5)`，保存误差与最小累积normal长度；略宽容差用于CPU分离乘加与CUDA FMA差异及归一化放大，不自动放宽失败项。回放不按normal_valid过滤，保持宿主原行为；非有限normal导致assert失败而不伪称通过。此检查约束采样像素的normal读取及坐标语义，不认证未采样像素或几何真值。

每个view的NPZ和metadata.json均先写同目录临时文件、flush/fsync后`os.replace`，避免停机留下被误认完整的半文件。若中断发生在NPZ完成但metadata更新前，NPZ可能存在而manifest未列出，须总控核对已有文件后决定，不自动删除或重跑。

NPZ中`offsets[r]:offsets[r+1]`是该射线的全部成员，字段为`gaussian_id, depth, weight, alpha, transmittance, normal, normal_valid, plane_degenerate`；`pixel_xy`、`qualitative`、`replay`、`host_target`为射线级字段。成员存储顺序始终为原接受顺序；分析阶段只用索引排序。

normal来自宿主几何buffer，是**相机坐标下、带方向的几何normal**，不是世界坐标，不是每像素累积normal或RGB。比较使用归一化后dot，不取abs；不同视角不得直接比较。非有限、长度<=1e-8或零ray-plane退化回退都标记无效。宿主NaN分支会给normal `{0,0,-1}`，单看normal有限性会误判，因此另存plane_degenerate。其他数值或建模退化未必可被此标记穷尽。

## CPU分析与机制检查

```bash
python 实验/03_高斯场层归属探索/analyze.py --synthetic \
  --output 实验/03_高斯场层归属探索/结果/CPU机制测试
python 实验/03_高斯场层归属探索/analyze.py \
  --input 实验/03_高斯场层归属探索/结果/20261022_夜间/scan24 \
  --output 实验/03_高斯场层归属探索/结果/20261022_夜间/scan24_analysis
```

分析只读已有NPZ，不重新加载模型、不使用GPU。默认eta=.01，angle=15°；按需显式`--grid`才运行eta=.005/.01/.02 × angle=10/20°六组合，或单独`--eta --angle`。默认最多3张普通探索射线图，不是投稿图；`--plots 0`跳过matplotlib。输出rays.csv、summary.csv/json、groups.json及少量PNG，分析输出目录必须为空。随机统计排除所有qualitative行；groups.json仍保留其单独描述。

参考组织是**按代表深度稳定排序的贪心complete-link约束算法**，不是层次聚类或全局最优分割。深度条件为`max(z_i,z_j)/min(z_i,z_j)-1 <= eta`；几何版另要求所有有效成员对的带方向夹角<=angle。所有组内成员对都必须通过条件，避免单链接桥接；可跨越深度排序中的其他组成员，因此允许深度交错。若同时可入多个组，按最坏归一化成对距离最小、再按组创建顺序决定，记录此局部歧义；另报告不同组间仍相容的成对数量。无效深度、几何版的无效normal均保留label=-1“未确定”，不假装已知单成员层。默认深度排序、tie顺序及阈值影响输出；全局单位缩放不影响相对深度条件，但近远尺度与实际几何分辨率并不等价。

权重只用于各组原渲染贡献质量(sum w)及比例、未确定贡献质量的描述，**不参与归属、不等于真实支持强度**。真实场景仅报告候选组数、成员数、贡献、深度范围重叠/交错及规则歧义，没有独立标签不报真实accuracy。跨组仍相容不是已证实误拆；零歧义也不能认证表面。

合成数据六个设定生成机制：单来源、深度分离双来源、深度重叠方向可辨双来源、深度方向都不可辨双来源、极弱贡献真实成员、弱桥。已知标签用于成对precision/recall/F1，同时惩罚误合与误拆；没有预测正对时precision为空，不能用单成员分组刷purity。无效normal另核查pair recall会降低。

本地2026-10-22使用Python3.13与numpy2.3.5完成六类CPU机制测试和两文件py_compile；小指标见`CPU机制指标.csv`。方向可辨重叠案例中depth F1=.5、depth+normal F1=1；方向也不可辨时两者F1=.5（预期失败）。其余四类两方法F1=1，仅说明设定机制下代码符合预期。另检查无效normal保留、单成员过拆F1=0、全局单位缩放不变及重复确定性。本地没有torch/CUDA和matplotlib，未本地编译CUDA、未本地验证真实模型回放、未生成PNG；云端运行须补齐，不能把CPU通过当作真实几何证据。

normal相容不是识别表面的充分条件；同向近表面、分辨率不足、模型偏差、视角相关几何提议都可不可辨。同一真实表面的normal变化也会误拆。单射线不能恢复宿主early-stop、alpha阈值或tile剔除隐藏的成员/表面。此原型不输出真实表面定位、不证明重建收益、不涉及训练梯度。
