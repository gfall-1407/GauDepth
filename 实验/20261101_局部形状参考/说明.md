## 给 Sol 的有限定义

输入一个**固定局部支持集合**的世界空间 Gaussian 参数 `(mu, R, s, a)`，其中 `s>0,a>0`；在实际宿主中拟使用 3D filter 后的尺度、opacity。现有捕获包没有后两者，因此本轮的真实数据部分没有运行这个密度场，也没有把逐像素 alpha 冒充 a。

`Q_i=R_i diag(s_i^-2) R_i^T`，`phi_i(x)=a_i exp[-(x-mu_i)^T Q_i (x-mu_i)/2]`，`pi_i=phi_i/sum(phi)`。

设 `n_i` 是最短轴，`gamma_i=1-s_min^2/s_mid^2`，构造 `B(x)=sum pi_i gamma_i n_i n_i^T`，取最大特征向量 `n(x)`。令

```
g(x) = grad log sum(phi_i(x))
F(x) = n(x) dot g(x)
x(z) = camera_origin + z * world_ray
```

`world_ray` 必须对应相机方向 `[(u-Cx)/Fx,(v-Cy)/Fy,1]`，保持 camera-z 单位，不归一化为射程。

`root_branches` 在外部给定的有限 z 区间用 256 格符号变化搜索、55 次二分，返回找到的根及稳定性、实际表面法向、特征值间隙和局部有效支持数。相邻样本先对齐特征向量符号，二分使用固定局部定向；最终要求无量纲残差 `abs(F)/sqrt(sum pi_i trace(Q_i))<=1e-8`，防止定向跳变被误报为根。根需满足 `n^T Hess(log rho)n<0` 且 `F_z!=0`。退化法向（间隙<=1e-10）拒绝；数值容差不是已标定的训练置信度。

这是**有界根候选生成器**，有限网格可能漏掉窄峰、同格多根和非变号根；不宣称完整枚举、不选最前或最高根。无效二分区间跳过，不当作表面。原型只适用于局部特征值不交叉、分支稳定、非切触的区间。单高斯尺度排序也必须局部固定；相邻尺度相等时log-scale JVP明确拒绝，不能只靠全局B特征间隙冒称可微。可见分支由另一研究接口提供；本线程交付局部几何部分。

## 梯度与宿主边界

`b_i=-Q_i(x-mu_i)`，`g=sum pi_i b_i`，`H=sum pi_i(b_i b_i^T-Q_i)-g g^T`。

`grad F = H n + (Jacobian n)^T g`。代码用对称矩阵特征向量的解析 JVP 计算 `dn`，没有 detach n。固定简单根上 `dz/dtheta=-F_theta/F_z`，已实现中心、log尺度、世界空间旋转微扰、log幅值的解析导数。PM 连续查询的投影坐标也必须保留梯度；参考核对了射线 x 分量的导数。

实际表面法向为 `normalize(grad F)`，不是 n。返回法向面向相机。本参考核验的是深度的隐式梯度及 F 的空间导数，**尚未实现/核验 surface_normal 输出的参数反传**；若把该法向接入 NCC，还需其含根位置变化的完整梯度，不能静默 detach。不新增可训练参数或损失，但尚未决定 native rendered-normal 的训练兼容方式。未来接入必须同时覆盖 render、continuous sample、mesh，并审查 depth-normal 与 NCC 的法向使用；不能仅修改渲染输出就称训练插件完成。

## CPU 已验证结果

运行标准库参考，所有断言通过，具体数值见 `cpu_results.json`：

- 不均匀切向分布、不同幅值/厚度的共面高斯：返回真实 camera-z `1.6326530612244898`。条件是所有中心共面且短轴共同垂直该面；此时 `F` 的法向分量仅与到面的距离成比例。
- 共面处若第i个中心沿共同法向的坐标为h_i，则 `dz/dh_i = (pi_i/sigma_i^2) / [(n dot ray) sum_j pi_j/sigma_j^2]`。本例所有中心导数为正，乘入n dot ray后总和1；幅值导数为0（浮点误差内）。这是不用stop-gradient即可把单面几何监督分配给局部成员、同时对幅值变化不敏感的条件性质；近似单面及真实训练是否保持优势尚待证伪。
- 对称双层，sigma=0.1、间距0.3：稳定根约1.853676和2.146324；中点2的法向曲率为+125，被拒绝。两根稍向内偏，不能宣称精确恢复两个输入平面。
- 对称双层间距0.1：唯一稳定根2，曲率-75，位于两面之间。这是明确失败域；对称等宽等幅情形的分岔界是间距2sigma，不是一般混合物分离保证。
- 幅值比0.01：间距3sigma时弱分支消失，5sigma时两个分支仍存在。说明间隔和相对强度共同决定可分辨性，不能只给一个普适2sigma规则。
- 所有幅值同乘1e-9，根完全不变；局部几何不携带绝对 opacity 置信度。0.005幅值的独立前方浮点也能产生稳定根，应由可见性/支持置信度接口处理，不因此否决整个局部算子。
- 各向同性输入明确拒绝。混合法向例子中，引导法向与实际表面法向夹角24.56度，说明省略 `dn` 或把 n 直接交给 NCC 会改变算子。
- Sol high只读独审发现的法向朝向跳变伪根和尺度排序不可微边界均已加入回归：固定局部定向与残差检查拒绝z约2、实际F约7.907的伪根；尺度相等处的log-scale导数明确拒绝。
- 六个非平凡参数方向的解析隐式导数与重新求根有限差分最大相对误差约8.47e-9；查询射线导数绝对误差约2.51e-8；空间导数相对误差约2.06e-9；刚体变换后的根误差0。

这些结果证明有限定义可计算、有条件单面一致、梯度可核验；没有证明训练收益或新颖性。

## 相关工作边界

- [RaDe-GS](https://arxiv.org/html/2406.01467v1)：单高斯射线密度极值与局部仿射近似。本参考估计局部混合场的法向驻点。
- [PGSR](https://arxiv.org/html/2406.06521v1)：混合平面距离/法向后求交；本参考的响应及法向随x变化，不是固定平面参数一次加权。
- [GGGS](https://arxiv.org/html/2601.17835v1)：连续透射率0.5求根和隐式梯度；“多成员可微求根”本身不是本方案的新颖点。
- [经典密度脊](https://www.jmlr.org/papers/v12/ozertem11a.html)、[IMLS](https://arxiv.org/html/2103.12266v2)：法向驻点/局部加权平面零点已有先例。本参考属于此类几何估计思路，不主张首次提出。
