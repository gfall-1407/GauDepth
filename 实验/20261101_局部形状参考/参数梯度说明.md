# 固定 density-ridge 分支的 CPU 梯度参考

这是从 `research/local-shape-cpu-20261101` 的 `63f2bef` 建立的独立工作树，只为既有定义 `F=n(x)^T∇logρ` 增加参数梯度。公开接口为 `local_shape_grad_reference.selected_root(mu, scale, omega, amplitude, base_rotation, origin, world_ray, bracket, camera_forward=None)`，输出固定括区内稳定根的 camera-z 深度 `z`、世界坐标实际表面法向 `∇F/||∇F||` 和诊断。调用方必须传入 `world_ray=R_c2w[(u-cx)/fx,(v-cy)/fy,1]`，不能把射线单位化成射程，也不能要求世界坐标的 `world_ray[2]=1`。传入世界坐标单位 `camera_forward=R_c2w[0,0,1]` 时，接口用 `camera_forward·world_ray=1` 校验；不传时由调用方履行这一契约，可单独调用 `validate_camera_z_ray`。`omega` 是作用于固定 `base_rotation` 左侧的世界坐标旋转向量；`scale`、`amplitude` 是正的实际值，因此梯度直接对应这两组值。支持对中心、尺度、旋转向量、幅值、相机原点和 query ray 的一阶反传。

根选择与最短轴排序是离散步骤，反传只在给定的单一稳定根、固定排序及局部符号图内成立。由 `dz/dθ=-F_θ/F_z` 传播深度；法向通过参数对 `∇F` 的直接作用及根位移共同传播。`∇F=Hn+(∂n/∂x)^Tg`，没有把 guide normal 当成实际法向。主特征向量使用仅依赖主特征间隙的线性系统 VJP；即使两个次级特征值并列，共面案例也有定义，避免完整 `eigh` 反传在该处的 NaN。

退化输入显式报错：非有限或非正幅值/尺度、尺度轴排序并列、主特征间隙不足、非稳定根、`F_z` 太小、非根残差、法向长度不足、符号图边界、相机 z 参数化不符。没有把退化值 clip 成“成功”。括区应由调用方预先固定且确认属于同一分支；有限二分网格未证明枚举所有根，接口没有可见性选择。

运行：`C:\Users\guofa\miniconda3\envs\gaussian_splatting\python.exe local_shape_grad_reference.py --output grad_results_v2.json`。旧 `grad_results.json` 保留原错误射线约束的审计记录。共面、双层前后稳定根、混合法向四例均用双精度，在每个扰动后重新求同一括区的根，逐项比较 `1.3*z + [0.2,-0.3,0.4]·normal` 对全部参数组的 VJP；最大相对误差 `1.12e-7`。变法向例另经 `torch.autograd.gradcheck`，实际法向与既有纯 Python reference 最大差为零；该例 guide 与实际法向相差约 `24.56°`。另对全部几何和 query 做整体旋转/平移一致性检查：旋转后世界射线 z 分量为 `0.8231`、相机前向轴点积为 1，深度误差 `4.44e-16`、实际法向误差 `2.25e-15`、梯度误差 `1.22e-13`；单位化射线被拒。四例端到端有限差分检验约 `4.1/1.0/1.0/2.5` 秒，精确逐例 forward 和 forward+backward 时间在 JSON 中。测试的是合成数学正确性，没有训练、CUDA、真实模型参数映射或 GT 精度证据。现有 capture 的 amplitude/opacity 层级并不完整，本接口不声称已接到 native accepted alpha 梯度。
