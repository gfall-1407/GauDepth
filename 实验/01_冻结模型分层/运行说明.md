# 冻结模型分层实验

源码基于 `8474727`，分支 `experiment/depth-layering`。只读原 `outtest/scan*/point_cloud/iteration_30000`，不训练。原 expected 网格和 `vis/results.json` 直接复用；新网格、评价、深度和邻接元数据均写入本目录。

`layered_depth.py` 调用原已安装 rasterizer 的 forward；`ray_trace_layered.cu` 读取该 forward 缓冲区，重放原接受/early-stop 条件，分批取得全部 z-depth 与原贡献。超容量按实际数量重取。CPU 批量排序保留原权重，不重算遮挡。三个规则严格按现有实验设计：固定相对间隔 1%；正 log-depth 间隔 median+3×未缩放MAD（少于四个正间隔回退固定规则）；贡献加权 FD 形式直方图（4–64 箱，零 IQR 用16箱），一次端点复制 `[1,2,1]/4` 平滑，半峰低谷切分。等深度保留接受顺序；贡献精确并列选较近均值。若多个非连续最低谷同值，确定性取第一个最低谷平台中心。

`mesh_extract_layered.py` 使用原 `extract_mesh` 函数体，仅替换深度来源、复用已加载模型/相机并重定向网格路径。RGB、mask、全部训练相机顺序、CPU Open3D VoxelBlockGrid、voxel=0.002、block_resolution=16、block_count=50000、depth_scale=1、depth_max=8、默认截断参数、原连通分量后处理（num_cluster=1）不变。`evaluate_dtu_mesh_layered.py` 使用原相机尺度/刚体对齐函数体，调用未改动的 `dtu_eval/eval.py`；随机生成器不变，不加 ICP、平滑、补洞或额外深度过滤。

DTU 使用原 mesh 模式，downsample_density=0.2、patch_size=60、max_dist=20、visualize_threshold=10，ObsMask/Plane 筛选不变。距离均值包含原协议的筛选和截断，Completeness 是距离，不是覆盖百分比。两张 raw/post 图采用同一0000相机、完整三角形的 CPU 投影绘制，只供定性对照，不参与评价。

云端在原 `radegs` 环境执行；只增加本目录的 ninja 构建依赖和独立扩展缓存。示例（从仓库根目录）：

实际环境为 Python 3.12、PyTorch 2.13.0+cu130、Open3D 0.19.0、RTX 4090 D。已核对 Open3D 当前两个 TSDF 调用的默认 `trunc_voxel_multiplier=8.0`；原调用继续采用默认值，不新增参数。15场景原相机 ID 均连续：24/37/40/55/63/65/69 为0000–0048（49视角），其余8场景为0000–0063（64视角），与原评价前 N 个 DTU 校准相机对应。原源码经归一化 CRLF 后的 SHA256 两端一致；原三个脚本及渲染源码未修改。

```bash
E=$(echo /root/autodl-tmp/GauDepth/*/01_*)
export OMP_NUM_THREADS=16 OPENBLAS_NUM_THREADS=1
export PATH="$E/dependencies/bin:$PATH" PYTHONPATH="$E/dependencies:${PYTHONPATH:-}"
python "$E/mesh_extract_layered.py" -m outtest/scan24 --check_only

# 核对 Scan24 指标和 raw/post 细节后固定候选：
nohup python "$E/run_layered.py" --selected contribution_valley > "$E/validation_corrected.log" 2>&1 < /dev/null &
```

先报告 Scan24 全部五种方法，以其 Overall 较低的自适应候选冻结规则，再依次在 Scan105 和其余13场景验证；这是探索选参。`结果表.csv` 包含各场景指标和方法均值，均值行明确注明实际场景数量。原评价使用无固定种子的采样，小幅差异应考虑采样波动。云端保存完整深度与 raw/post 网格，本地只同步源码、表格、必要统计及少量对照图。任务结束先落盘同步，再仅关闭 AutoDL 实例。

## Scan24 首轮选择

49 个相机按 `0000`–`0048` 排序，图像为 777×581，与原分辨率一致，原对齐采用前49个 DTU 校准相机，视图 ID 对应一致。核对使用 `rtol=2e-5, atol=2e-6`。超容量重取完整射线，未接受截断记录。读取扩展必须匹配宿主 setup.py 的 `-O3 --use_fast_math`，focal 必须沿用宿主 float32 tan_fov 计算；这里的 fast-math 是保持原接受循环数值，不是改变原模型或原扩展。

首次读取扩展漏配宿主 fast-math，在 Scan37 发现一个 median 阈值像素不匹配；修正编译选项及 focal 计算后，Scan37 首视图451437像素通过。修正前分层数值作废，分层网格与评价完整重做，原 expected 和直接读取宿主 median 的结果保留。不得将旧分层图或旧分层指标作为最终结论。

修正后 Scan24 Overall：expected=0.37049007，median=0.36617072，固定1%=0.36608311，自适应间隔=0.38490421，贡献低谷=0.36393541。贡献低谷的 mean_d2s=0.33273280、mean_s2d=0.39513803，两者均低于原 expected；同视角 raw/post 对照未见明显额外的窗户或屋顶轮廓缺失。选择并冻结贡献低谷首版，保留自适应间隔的负结果。这是 Scan24 探索选择及单视角定性核对，不能据此宣称整体细节改善。

修正后 Scan105：expected=0.52224181，median=0.57187974，固定1%=0.53455754，贡献低谷=0.54984925。三种新对照均比原 expected 差，不因此改变冻结设置。距离指标为 mm，沿用[DTU 官方评价论文](https://roboimagedata2.compute.dtu.dk/data/text/multiViewCVPR2014.pdf)的参考坐标单位；模型空间 TSDF 的 voxel=0.002 仍为原模型单位，不按毫米替换。
